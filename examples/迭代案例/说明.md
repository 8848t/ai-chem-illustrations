# 迭代案例：动态平衡迷思漫画 v2 → v3

一组真实的"错误版 → 修正版"对照，展示局部编辑迭代的完整过程。

## v2 的问题（动态平衡_v2_逆反应方向错误.png）

容器中部下行的"逆反应"转化事件里，微粒放反了：沿向左的箭头读过去是"两个单圆结合成双圆"——与上行"正反应"画成了同一个方向，"逆反应"名不副实。这属于**结构性排布错误**（转化方向与箭头不符）：模型不会自动理解"逆反应=拆分方向"这一隐含约束。

## 使用的局部编辑指令

```text
对上图做局部编辑：将下方"逆反应"箭头两侧的微粒对调——双圆相连的分子放在箭头尾部（右侧），
两个单圆放在箭头指向的一侧（左侧），使其正确表示"双圆分子拆分为两个单圆"；
"逆反应"标签与箭头本身（长度、粗细、方向）不变；其余一切保持完全不变。
```

## v3 的结果（动态平衡_v3_修正后.png）

逆反应行修正为拆分方向，上行正反应、容器、散布微粒、两个角色、气泡文字全部未受扰动。

## 可迁移的经验

1. 转化/流向类画面要在提示词里写清**箭头两侧各放什么**（"双圆在箭尾一侧、两个单圆在箭头所指一侧"），不能只写"画一个逆反应"；
2. 局部编辑指令要同时点名"改什么"与"什么保持不变"；
3. 修改后整体复查图文对应（本案例未引发新错位，但实测中发生过）。
