# 局部编辑指令与迭代对策

生成的图片只有单处错误时，优先用局部编辑而非整图重生成——改动小、其余画面保持稳定。

## 基本指令模板

```text
对上图做局部编辑：仅〔要改的内容，如：删除左筒右上方那个空心圆，使左筒恰好 8 个分子〕，
其余所有分格、构图与全部中文标注保持完全不变。改完后整体检查图文对应关系。
```

**局部编辑后必须整体复查**：修一处可能引发新的图文错位（实测发生过——修掉画面元素后，原标注与新画面不再对应）。

## 常见问题 → 对策

| 问题 | 对策 |
|---|---|
| 单处画错（多余/缺失/位置偏） | 局部编辑指令，点名"仅修改××" |
| 中文错字 1~2 处 | 局部编辑改字；错字多则重生成并缩减标注数量 |
| 微粒数目不对 | 回模板把计数写成"恰好 N 个"再重生成；**生成后务必逐个清点，AI 自称"已核对计数"不可信** |
| 结构性错误（排布、方向、连接） | 局部编辑难以修复，回模板显式写明正确结构后重生成 |
| 角色风格漂移（眼睛、体型变样） | 重生成，在提示词里强化角色描述关键词 |
| 举牌/标语空白 | 指定牌面内容后局部编辑或重生成 |
| 转化方向类错误（如逆反应箭头两侧微粒错位） | 局部编辑"对调箭头两侧微粒"，明确哪侧放什么 |

每张图经 1~4 轮迭代达到可用属于常态。保留所有版本（v1、v2……）与对应提示词，既是过程档案，也是给同事复用的资产。
