# 提示词模板

方括号〔〕处按各图需求填空，整段复制进对话式 AI 工具即可。也可用 [`../assembler/index.html`](../assembler/index.html) 网页装配器填空生成。

```text
生成一张独立的 16:9 横版中文高中化学教学插图。
【风格】纯白背景；极简黑色手绘线稿，笔线轻微抖动；大量留白；少量手写体中文标注，只用红/橙/蓝三色平涂。禁止：渐变、阴影、商业矢量风、PPT 信息图、幼稚儿童插画；图上任何位置不写标题。
【角色】小黑：小型全黑实心怪物，白色圆点眼，细腿，表情呆滞认真。本图道具：〔护目镜/白大褂/胡子/无〕。小黑正在〔承担的核心动作〕。
【主题】〔教学主题〕
【结构】〔四格分镜/左右对比/三区布局/单场景〕，逐格描述：〔第1格：画面＋标注（逐字）；第2格：……〕
【显式化】涉及即写明：微粒"恰好 N 个"并两侧守恒；位置用"A 的 X 端对准 B 的 Y 处"句式；结构式逐原子指定成键。
【标注】图内只允许出现以下文字，逐字使用，不得增减：〔标注1/标注2/……〕
【约束】化学准确性最高优先；〔本图特有约束〕；留白至少 30%；有趣但不幼稚。
```

## 五个要素为什么这样设计

1. **统一风格**——纯白背景、黑色手绘线稿、红橙蓝三色分工（红＝警示与关键结果，橙＝主流程，蓝＝补充说明）。既保证系列感，也保证黑白打印可辨；画面元素越少，模型可出错之处越少，极简是对抗生成错误的防御性设计。
2. **固定 IP 角色**——为学生提供熟悉感与注意锚点，使抽象过程获得"谁在做什么"的叙事线索；文字描述整段复用是系列图片风格一致的主要保障。**注意：角色可以"操作、观察"微观世界，但不要扮演原子、分子本身**（微粒拟人化易诱发迷思概念）。
3. **显式化三件套**——微粒数目（"恰好 N 个"且两侧守恒）、相对位置（"A 的 X 端对准 B 的 Y 处"）、成键连接（"每个碳原子恰好四个键"）。凡涉及必须逐一写明，不能默认模型"知道"。这是科学性的主要保障。
4. **图内文字白名单**——允许出现的中文标注逐字列出并声明"不得增减"，可大幅减少乱字与多余文字。
5. **逐格描述**——多格漫画按分格逐一写明画面与标注，不给模型自由发挥叙事的空间。

## 实操提示

- 涉及**实验操作**的画面，提示词里默认写明规范操作（如"沿烧杯内壁缓缓倒入""玻璃棒仅用于搅拌""用电加热而非明火"），AI 不会自动画规范；
- 让角色**举牌/持标语**时必须指定牌面内容，否则大概率生成空白牌；
- 风格与角色都是可替换槽位：整体换成你自己的风格描述与班本角色，模板结构、显式化要求与质检流程不变。
