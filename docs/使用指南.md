# 使用指南

## 五步操作（全程在对话式 AI 聊天框完成，不需要编程）

1. **选工具**：支持文生图的对话式 AI 均可（GPT 系列、豆包、即梦、通义等）。有分辨率档位的选高档位——印刷用途一般要求图片宽度不低于 1700 像素；
2. **填模板**：用 [`../prompts/模板.md`](../prompts/模板.md) 或 [`../assembler/index.html`](../assembler/index.html) 填空，整段发送；
3. **初检**：对照 [`../checklist/质检清单.md`](../checklist/质检清单.md) 逐项核验；
4. **迭代**：单处错误发局部编辑指令（见 [`../prompts/局部编辑指令.md`](../prompts/局部编辑指令.md)）；结构性错误回模板加强显式化后重生成。每张图 1~4 轮属常态；
5. **存档**：保存"提示词 ↔ 成图"对应档案。同一提示词两次生成结果不同，档案既便于复用改编，也便于同事共享。

## 先分流：这张图该不该用文生图？

| 适合文生图 | 不宜文生图（改用其他工具） |
|---|---|
| 实验现象漫画、安全教育漫画 | 精确实验装置图（蒸馏、气体制备等） |
| 迷思概念漫画、情境导入图 | 坐标曲线图、数据图表 |
| 化学史场景、科普海报与连载 | 复杂结构式、环系有机分子 |
| 显式计数的简单微粒示意图 | 元素周期表等有严格排布约束的图 |
| 简单结构式（逐原子指定连接） | 考试命题用图 |

## 应用场景速查

- **课堂**：情境导入（化学史场景）→ 现象讲授与复习（多格现象漫画）→ 微观过程可视化（显式计数微粒图）→ 概念辨析（迷思漫画"哪种说法对？"投票辩论）；
- **资源建设**：单元系列插图（如海洋资源 12 格）、复习图集内页（如原子模型时间线）、科普连载（如暖宝宝四格）；
- **学生活动**：评图找错（用质检清单当支架）→ 小组选题创作（家庭实验记录、生活化学调查、安全海报）→ 展评。学生作品公开展示前须教师终审。

## 跨工具使用说明

模板的核心策略（显式计数、位置句式、文字白名单）在不同模型间可迁移，但**错误类型与频率随模型而异**——实测同一提示词在某国产轻量模型上出现了原模型没有的错误（钠球沉底、个别中文错字）。结论：换什么工具都不能省质检环节。完整复测记录见 [`../prompts/样图提示词档案.md`](../prompts/样图提示词档案.md) 第一节。
